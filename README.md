# Training Dynamics of Learning 3D-Rotational Equivariance

This directory contains code for downloading wandb metrics and generating plots for the paper 'Training Dynamics of Learning 3D-Rotational Equivariance' (TMLR, 2025).

Wandb metrics of equivariance metrics are generated by running training scripts in the escaip, proteina, and voxmol directories.
